# SubLingo: MVP

## Входит
- Язык: английский -> русский
- Источник: .srt от пользователя
- Анализ серии: леммы, частота, CEFR, фразовые глаголы
- Стартовый placement-тест
- Упражнения: cloze и выбор значения
- Интервальное повторение (FSRS/SM-2)
- Офлайн-кэш (Room), JWT-авторизация

## Не входит
- Книги, другие языки
- OpenSubtitles API, Whisper
- Социальные функции, геймификация
- iOS

## ML-ядро (метрики)
- Модель знания слов: AUC, log-loss
- WSD: accuracy/F1 против baseline
